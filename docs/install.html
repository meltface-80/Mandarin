Install the server

Run the server on Mandarin OS, on an always-on computer of its own on the same network as your speakers: installed from a USB stick, with a web page of its own to watch over everything and nothing else to look after.

Mandarin OS

A lightweight operating system made only to run Mandarin Server, on a computer of its own (a mini PC such as a Dell OptiPlex Micro or an Intel NUC), with a web page of its own, the system page, to watch over and look after everything. Write its image to a USB stick, start the computer from it and answer a few questions; from then on it looks after itself, with a shared folder, smb://<box address>/data, for your music, and USB drives mounted as they are plugged in. From 0.1.4 it updates itself in place, and goes back by itself to the version that worked if a new one doesn't start (Updating Mandarin OS; 0.1.3 and earlier reinstall once to get it).

  1. Download the imagemandarin-os-0.1.16-x64.img.xz for balenaEtcher or a Linux terminal, mandarin-os-0.1.16-x64.img for an Android phone. Downloads
  2. Make the USB installerWith balenaEtcher, dd or EtchDroid, on a stick of 4 GB or more. How
  3. Install itSecure Boot off, start the PC from the stick (F12 on a Dell), and choose its disk, the shared folder's user and password, and the network. How
  4. Open Mandarinhttp://<box address>:3500, and the system page at http://<box address>/. Using Mandarin OS

Music folders, chosen in the app: add any folder the server can read in Settings → Music Folders, as many as you like, and remove them there too. A folder that goes missing for a while (a drive asleep, a share that dropped, part of it unreadable, most of it gone at once) keeps its albums; the page says so and offers to forget it.

  3. Tap an album and Play Now.

Updating

In the app: Settings → Updates → Check for update beside the server → Update available. The server downloads the new release from GitHub, checks it against the release's sums, swaps it in and starts again in a few seconds; a browser's page reloads on its own. In the Android app the app has its own Check for update beside it, and each Mandarin Bridge has a row of its own. It also checks twice a day and shows a banner when a new version is out. On Mandarin OS, Mandarin updates the same way, and Mandarin OS itself from its system page (Updating Mandarin OS).

Mandarin's server is one program, in C#. An update from the app fetches that program of the new version for your machine (x64 or ARM64) from the release, checks it against the release's sums and its signature with Mandarin's release key (a release replaced along with its sums is refused), puts it and the new page in place, and starts again in the same process — a few seconds. If it can't start again in place, it stops and its systemd service starts it again.

The new program is checked and laid in beside the old before anything is swapped: if something fails after the swap, the old one (kept as mandarin-server.prev) is put back, and a folder the release can't be written over is named before anything is changed.

The Mandarin Bridges

Every Bridge Mandarin knows, on Android, Linux or a Raspberry Pi, has a row of its own on Settings → Updates, its name and version, and its own Check for update, as the server's and the app's rows: it asks GitHub now and becomes Update available when a newer build is published for it (the rows also find one by themselves within a minute or so). A tap on Update available asks the Bridge to update itself: it fetches the release from GitHub, checks it against the checksum published with it and its signature with Mandarin's release key, and puts it in place.

  • Linux and the Raspberry Pi: in a few seconds, by itself. The new build goes in the Bridge's data folder and the program installed hands over to it as it starts again; one that fails as it starts is let go, and the installed one runs on.
  • Android: Update puts a notification on the device; its tap downloads the update in the browser, and Android's installer asks you to install it. The Bridge holds no permission to install apps itself.
  • An Android Bridge from before v0.2.1, or a Linux or Raspberry Pi Bridge from before v0.3.1, needs one last update by hand, from Downloads.
  • A numbered Mandarin follows the Bridges' numbered releases (Mandarin Bridge v0.3.21 with Mandarin v1.3.8).
