On your phone

The same interface everywhere, because it comes from the server.

Android

Mandarin Remote, the Android app

Enter the port (3500 unless you changed it) and it finds the server on your Wi-Fi by itself, or type the address; then sign in, create the account on a new server, or use it without one. On top of the interface it adds lock-screen and notification controls, volume keys, a now-playing widget, a Quick Settings tile, a share sheet, Android Auto, This phone as a room, downloads, a USB DAC driver, and Tailscale for away from home.

⬇ Get it from Downloads

Sideload it on Android 8.0 or newer; it updates itself from then on, from Settings → Updates. Installed before v0.6.10? Those builds used a different signing key, so Android refuses the update. Uninstall once, install the download and sign in again; downloaded albums need downloading again. Updates install in place after that.

A native app (Kotlin and Jetpack Compose), in android/. The download, mandarin-android.apk, is the newest build, published by GitHub Actions on every version merged to main; the build itself is named Mandarin-Android-<version>.apk, and the link keeps one name so it always points at the newest. Building the app yourself? Without the MUSICD_KEYSTORE_BASE64 and MUSICD_KEYSTORE_PASSWORD secrets, a build is signed with the shared key committed in the repository (android/app/musicd-debug.keystore) and named …-shared-key.apk. It can't update the published app, nor the published app it.

iPhone & iPad

Add to Home Screen

Open http://<server-ip>:3500 in Safari, tap Share → Add to Home Screen. It opens full screen like an app, with the same interface as the Android app.

Out of the house, the Android app keeps playing over mobile data: see Away from home. The app's own features are on Features.
