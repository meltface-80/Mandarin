Settings for the server

All optional; set any as an environment variable of the server (installed on Linux: sudo systemctl edit mandarin, then Environment=NAME=value under [Service]). Mandarin OS sets what it needs itself, with no shell to change them in. Everything else is in the app's Settings and kept in the data folder.

VariableDefaultPurpose
PORT3500The web interface, the API, and where speakers fetch audio.
TZUTCYour time zone — Album of the day changes over at 00:01 and Smart Picks at local midnight.
SONOS_HOSTS—A speaker's IP (comma-separated for several), for when multicast discovery is unreliable. One is enough.
ART_HOSTS—Hosts on your own network a picture may be fetched from (comma-separated names or IPs): a radio station's logo served at home, say. Mandarin never fetches a picture from its own machine or your network otherwise; the Sonos speakers' own addresses are always allowed.
UPNP_HOSTS—UPnP/DLNA renderers to ask by address (an IP, or a description URL like http://192.168.1.50:49152/description.xml), for when multicast discovery misses them.
SERVER_IPautoThe address speakers fetch audio from. Auto picks the machine's LAN address, skipping VPN, container and VM interfaces, and searches for speakers on every LAN interface. Set it to pin one.
INCLUDE_ZONES—Offer only these rooms, e.g. Kitchen,Study.
EXCLUDE_ZONES—Offer every room except these.
SCAN_INTERVAL_HOURS6How often the music folders are re-checked in full (only changed files are re-read). Between those, an album copied in or deleted is noticed as it happens: through the file system's own notifications, and on a network share or FUSE folder (SMB, NFS, mergerfs), whose changes made elsewhere aren't told, by looking at its folders every 30 seconds. A deletion shows a few seconds after it; a long copy is read at least every 30 seconds while it goes on, so albums appear one by one. Rescan any time from the menu.
TRANSCODE_CACHE_GB4Disk kept for converted tracks. An upsampled track is several times a CD-rate one: with upsampling on, 16 is a better number.
TRANSCODE_CONCURRENCY2How many tracks are converted at once.
PLAYBACK_CORESautoProcessor cores kept for playback alone: one, or two while DSP is in use. 1 or 2 fixes the number; 0 shares every core. Settings → Library Scanner → Processor shows the split.
MUSIC_DIR/musicThe first music folder, until you change the list in Settings → Music Folders (the Linux installer sets it from --music).
TRUSTED_PROXIES—Reverse proxies whose word on who asked is believed (addresses or ranges, comma-separated): 127.0.0.1 for an nginx, Caddy or tailscale serve on the same machine. The built-in Tailscale needs nothing here.
TS_AUTHKEY—Sign the server's built-in Tailscale in with an auth key instead of from Settings → Setup → Away from home.
TS_HOSTNAMEmusicdThe server's name on your tailnet.
TAILSCALEonoff leaves the built-in Tailscale out (Tailscale on the host still works).
SQTOOL_PYTHONpython3The Python 3 (with numpy) that runs SQ-tool.
TAILSCALE_ADDRESSautoThe server's address away from home, if the one found on the host's tailscale0 isn't the one to use — an IP, a MagicDNS name, or a full https:// address. See Away from home.
MUSICBRAINZ_URLmusicbrainz.orgAnother MusicBrainz web service (a mirror) for the identification scan, release days and an album write-up's year.
IDENTIFYon0 leaves the identification scan out entirely.
MBPACK_DIRdata folderWhere the MusicBrainz pack is kept (Settings → Library Scanner); overrides the folder chosen there.
ITUNES_COUNTRYUSThe Apple store the identification scan's iTunes lookups use (GB, DE…).
AUTOEQ_URLGitHubWhere AutoEq's results are read from for headphone profiles (Settings → Audio Devices → a device → DSP).
LASTFM_KEY—A Last.fm API key for similar artists and albums on album and artist pages, until one is saved in Settings → Setup → API Keys (which then wins). Scrobbling also needs the key's shared secret, saved there.
DEBUG—Log every API call.

The FanArt.tv key (artist photos), the waveform, Smart Picks, the wall display and the Home rows are set in the app's Settings and saved in the data folder.
