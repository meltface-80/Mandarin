What's new in v1.2.5

Mandarin v1.2.5, since v1.2.2, with Mandarin Bridge v0.3.4.

Versions of one album, one album

An original and its remaster are one tile, 2 versions under it. Versions are told by MusicBrainz's release group, else one act and one title with its version words off (2015 Remaster). The main is the highest resolution, or the one you choose with Make this the main version; the album's page lists every version with what tells it apart, a tap showing it in place. Features →

An album's page on a phone, redesigned

The cover on top, the date, rate and length under it, the title across the page; then Tracks, Credits, About and Versions as tabs, centred, held at the top as the page scrolls with the page cut off cleanly under them. Share card is in ⋯. In the browser and the Android app.

Clipping shown, and Headroom when upsampling

A track mastered to full scale clips between its samples when upsampled. Mandarin now counts every clipped sample and turns Now playing's line red; Headroom when upsampling (Auto) turns a track down by just what its true peak needs. Upsampling →

Keeping up, and a safety net

The signal path says how fast a track is being made (Keeping up at 4.2× real time). An Output the server can't make in time, or the device can't play, is put back to the last one that played well, the track carrying on. Signal path →

Changed

  • The music folders are followed as they change: an album shows as it is copied in, a deletion within seconds, and a network share's or a mergerfs folder's changes within half a minute, where they waited for the six-hourly scan.
  • Search's count (1 artist, 60+ albums) is under the search field, which keeps its width.
  • Extended ends an edition's title, as Deluxe and Remastered do: Radical Optimism (Extended) is a version of Radical Optimism.

Security

A security audit of this version found fourteen things to put right; every one is fixed.

  • The Docker image runs the server as a user, not root (1000 by default; PUID and PGID change it). Your data is handed over at the first start. Install →
  • Who sent a request is believed from forwarding headers only from the proxies named in TRUSTED_PROXIES and the built-in Tailscale. A reverse proxy on the same machine needs TRUSTED_PROXIES=127.0.0.1. Configuration →
  • Covers from elsewhere are never fetched from the server's own machine or your network (but the Sonos speakers and hosts named in ART_HOSTS).
  • Addresses handed to speakers and players expire after 30 days, and a speaker asking without one gets only what it was handed.
  • Mandarin Bridge's port takes changes only as JSON, never from another site, and never updates backwards. A page on another port of the server's machine can't use your browser's sign-in either.
  • Scripts run only from Mandarin's own pages (a Content-Security-Policy).
  • With the sign-in off, only your own Tailscale devices count as home, not all of Tailscale's address range.
  • Releases can be signed, and the server's and the Linux Bridge's updates checked against Mandarin's release key.
  • Away from home, use Tailscale, never a port forward: the log now says when plain http arrives from outside. The workflows' actions are pinned, and a build that can be published needs the real signing key. Away from home →

Fixed

  • Settings → Updates couldn't update the server in Docker once it ran as a user (Access to the path '/app/.update' is denied): it unpacks elsewhere and lays in only what is the server's own.
  • An album that mixes sample rates played nothing with Albums as one stream on, when its Output made DSD or upsampled to the highest rate.
  • An album deleted from the music folders stayed on its artist's page, in the app and the browser.
  • The built-in Tailscale wouldn't start after the update to a non-root container (permission denied on its state).
  • The Android app's album tabs were squashed into a column of letters, and the headings under them said the tabs again.
  • Mandarin Bridge's update said only SecureConnectionError when GitHub's certificate was refused; it now says why (a wrong clock, missing certificates).
Updating: the server from Settings → Updates (in Docker, docker pull as before: the container now runs as user 1000 and hands its data over at the first start); the Android app beside it; each Mandarin Bridge from its own row. A reverse proxy on the server's machine needs TRUSTED_PROXIES=127.0.0.1. Every change is listed in the changelog.
