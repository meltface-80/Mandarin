What's new in v1.2.1

Mandarin v1.2.1 and Mandarin Bridge v0.3.0, since v1.2.0.

Mandarin Bridge

Updated: over SlimProto, Mandarin now sends Mandarin Bridge a continuous stream of PCM (DSD still goes as DSD). Mandarin Bridge →

More upsampling, for less

Gaussian, Long and Very long filters, minimum phase for each, a filter for CD-rate and one for hi-res sources, shaped dither at the DAC's real bits, three DSD modulators, and Output as recipes, made with far less of the processor. Upsampling and output →

Also new

  • Squeezelite players (and Squeezebox-compatible hardware) play from Mandarin over SlimProto, one track into the next from their own buffer, with Output's upsampling and seeking.
  • Albums as one stream: an album's tracks go to a device as one stream, gapless however it joins files.
  • A renderer's own player: where MPD is beside it, as on a Chord Poly, Mandarin can hand MPD the whole queue.
  • Native DSD on Linux: Mandarin Bridge for Linux says when the computer's kernel holds back a DAC's native DSD, and the one line that frees it. More →
  • A Linux server leaves its USB DAC to Mandarin Bridge for Linux, installed beside it: the server no longer opens the computer's sound cards, and the container needs no --device /dev/snd. A Mac's own outputs play as before.
  • The bar along the foot on every screen, Now playing too.

Fixed

  • Mandarin Bridge for Linux sends native DSD on Linux 6.x, where it misread the kernel's list and sent DoP.
  • A Bridge installed again is the device it was, not a new one each time.
  • A Bridge's ✓ on Now playing is asked again until it comes.
  • The Chord Poly: albums as one stream kept, PCM at 705.6 and 768 kHz as WAV, a track made DSD followed on into the next, 24 bits where it can't decode 32.
  • Mandarin Bridge for Android asks the browser to download its updates (Google Play Protect called installing them itself harmful).
  • A command the server doesn't have says so, rather than starting a second server.
Updating: the server from Settings → Updates; the Android app beside it; a Bridge from its own row there (on Android, a notification downloads it in the browser). A Bridge from before v0.2.1 needs one last update by hand, from Downloads. Every change is listed in the changelog.
