Install with Docker

Deploy on any always-on Linux machine inside the local network subnet (NAS, Raspberry Pi 4/5, or generic home systems). --network host is required to guarantee multicast discovery loops function correctly.

docker run -d \
  --name musicd-server \
  --network host \
  -v /path/to/music:/music:ro \
  -v musicd-server-data:/data \
  -e TZ=Europe/London \
  -e PORT=3500 \
  --restart unless-stopped \
  meltface-80/mandarin:latest

Note: Docker Desktop setups for macOS and Windows lack native host network layers—a production Linux kernel host environment is required.
