Downloads

The newest version of each, straight to your device. Mandarin is the server and the Mandarin Remote app; Mandarin Bridge turns a device with a USB DAC into a room. Run the server on Mandarin OS, the recommended way, or on Linux as the alternative.

Mandarin server

Recommended · Mandarin OS 0.1.6 · a 64-bit Intel or AMD PC with UEFI

Mandarin OS

A lightweight operating system made only to run Mandarin Server, with its own system page to look after it. Write it to a USB stick of 4 GB or more, start the PC from it and install. Once installed, it updates itself from its system page (how; 0.1.3 and earlier reinstall once).

⬇ For balenaEtcher or dd (.img.xz, about 360 MB) ⬇ For an Android phone (.img, about 1.6 GB)

Make the USB installer and install, step by step →

The alternative · v1.3.2 · Debian, Ubuntu, Raspberry Pi OS (x64 or arm64)

Linux

Mandarin installed natively on an always-on Linux machine you already run. One line as root: it installs what Mandarin needs and runs it as a service.

curl -fsSL https://raw.githubusercontent.com/meltface-80/Mandarin/main/tools/linux/install.sh | sudo bash -s -- --music /srv/music

Mandarin Remote: the Android app

v1.3.2 · Android 8.0 or newer

Mandarin Remote

Mandarin's interface drawn natively, finding your server at home or away. Install it once; it updates itself from then on (Settings → Updates).

⬇ Download the app (.apk)
iPhone and iPad

Add to Home Screen

Nothing to download: open http://<server-ip>:3500 in Safari and tap Share → Add to Home Screen. It opens full screen, like an app.

A device with a USB DAC on its port as a room Mandarin plays to, bit-perfect. Install the one for your device; it updates from Mandarin's Settings → Updates from then on. More about Mandarin Bridge →
