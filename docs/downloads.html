Mandarin Remote: the Android app

v1.3.0 · Android 8.0 or newer

Mandarin Remote

Mandarin's interface drawn natively, finding your server at home or away. Install it once; it updates itself from then on (Settings → Updates).

iPhone and iPad

Add to Home Screen

Nothing to download: open http://<server-ip>:3500 in Safari and tap Share → Add to Home Screen. It opens full screen, like an app.

Mandarin server

v1.3.0 · Linux, Raspberry Pi 4/5, NAS

Docker

The easiest way on an always-on Linux machine. The install page builds the full command with your music folders filled in.

docker pull ghcr.io/meltface-80/musicd-server:latest
Build the command →
v1.3.0 · macOS 14 or newer

Mac

No Docker needed, Apple silicon or Intel. Paste this line into Terminal and answer what it asks.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/meltface-80/Mandarin/main/tools/mac/install.sh)"
Step by step →

The server program on its own

The single server program for each kind of machine: what Settings → Updates fetches. Most people never need these; Docker and the Mac installer are simpler.

Mandarin Bridge

A device with a USB DAC on its port as a room Mandarin plays to, bit-perfect. Install the one for your device; it updates from Mandarin's Settings → Updates from then on. More about Mandarin Bridge →
