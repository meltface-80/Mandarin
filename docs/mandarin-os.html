Mandarin OS

A lightweight operating system made only to run Mandarin Server, with a web page of its own, the system page, to watch over and look after everything. The recommended way to run Mandarin. Version 0.1.6.

What it is, and why

A music server should be something you switch on and forget. Mandarin OS turns a small computer into exactly that: Mandarin and only what Mandarin needs, installed from a USB stick in a few minutes, with nothing else to set up or keep up to date. That is why it is the recommended way to run Mandarin; to run Mandarin on a Linux machine you already have instead, see Install on Linux, the alternative.

  • Lightweight: Debian 13 with Mandarin installed natively, and nothing else: no desktop, no login, no SSH. Everything coming in from the network is refused by a firewall, but what Mandarin and the system answer.
  • Its own web page: the system page, http://<box address>/, shows Mandarin, its services, the storage, the network and the logs, and does what you'd otherwise need a shell for: eject a drive, set a static address, install Mandarin Bridge, reinstall or reset Mandarin, restart or shut down.
  • A shared folder for your music: smb://<box address>/data. Copy music in from any computer, or plug in a USB drive: it is mounted, and in Mandarin, as it is plugged in.
  • Looks after itself: once a week, when nothing is playing, it takes a newer Mandarin OS or Debian's security updates, clears out what isn't needed, and checks that everything works.
  • Updates itself in place: a new version is written beside the one running, never over it, and started; if it doesn't start, the box goes back to the version that worked by itself. Your music, settings and drives aren't touched. Updating Mandarin OS

What you need

  • A 64-bit Intel or AMD PC with UEFI and a wired network (Ethernet): a mini PC such as an Intel NUC or a Dell OptiPlex Micro. Mandarin OS is made and tested on a Dell OptiPlex 3050 Micro.
  • A disk of its own for the system. Everything on it is erased. The system takes about 8.5 GB of it; the rest holds Mandarin's data and your music (Storage). Another internal disk, if the PC has one, can be internal storage.
  • A USB stick of 4 GB or more for the installer. Everything on it is erased too.
  • A screen and a keyboard for the install itself. After that the box needs neither.
  • Secure Boot off in the PC's firmware settings (BIOS/UEFI setup).

Download

The signatures, mandarin-os-0.1.6-x64.img.xz.sig and mandarin-os-0.1.6-x64.img.sig, are beside them on the release, with the system and kernel images (.root.raw.xz, .efi) an installed Mandarin OS updates itself from.

Make the USB installer

Three ways; choose whichever suits what you have to hand.

With balenaEtcher (Windows, macOS or a Linux desktop)

  1. Install balenaEtcher and download mandarin-os-0.1.6-x64.img.xz. Etcher takes the compressed file as it is: there is nothing to unpack.
  2. Plug in the USB stick and open Etcher.
  3. Flash from file: choose the .img.xz you downloaded.
  4. Select target: choose the USB stick. Check it is the stick: everything on it is erased.
  5. Flash! Etcher writes the stick, then checks what it wrote. Your computer may ask for your password.

When it says the flash is complete, take the stick out. (If Windows then offers to format the stick, as it can't read it, say no.)

From a Linux terminal

  1. Plug in the USB stick and find it: lsblk lists the disks by size. The stick is a whole device such as /dev/sdb. Double-check it: everything on the device you name is erased, and naming the wrong one erases that disk instead.
  2. If the desktop mounted any of its partitions, unmount them first (sudo umount /dev/sdX1, and so on for each).
  3. In the folder you downloaded to, check the download against its checksum (it should say OK):
sha256sum -c mandarin-os-0.1.6-x64.img.xz.sha256
  1. Write it to the whole device, /dev/sdX (not a partition such as /dev/sdX1), with sdX the stick's name from lsblk:
xz -dc mandarin-os-0.1.6-x64.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

From the plain image, the same without xz:

sudo dd if=mandarin-os-0.1.6-x64.img of=/dev/sdX bs=4M conv=fsync status=progress
  1. Then run sync, and take the stick out once it has returned.

From an Android phone, with EtchDroid

EtchDroid is free, on Google Play and F-Droid. It needs the plain mandarin-os-0.1.6-x64.img, not the .img.xz: a phone's writer doesn't decompress, and a stick written from the compressed file starts nothing. The stick goes into the phone through a USB-OTG or USB-C adapter (or a USB-C stick).

  1. Download mandarin-os-0.1.6-x64.img on the phone (about 1.6 GB: Wi-Fi is best).
  2. Plug the USB stick into the phone through the adapter.
  3. Open EtchDroid and choose to write an image (a raw image), then pick the .img you downloaded.
  4. Pick the USB stick.
  5. When Android asks whether EtchDroid may use the USB device, allow it.
  6. Confirm that the stick may be erased, and wait until EtchDroid says it has finished. Keep the phone awake and the stick in until then.

Install Mandarin OS

  1. Secure Boot off, in the PC's firmware settings, if it isn't already.
  2. Plug the network cable, a screen and a keyboard into the PC, and the USB stick.
  3. Start the PC from the stick. Switch it on and press its one-time boot menu key at the maker's logo: on a Dell, F12; other makers use keys such as F11, F12, F8 or Esc (the PC's manual says which). Choose the USB stick under UEFI.
  4. The installer comes up on the screen, with the version it installs at the top, and asks, in turn:
    • The system's disk, by its model and size. Only the PC's internal disks are offered, never the stick or a USB drive. Everything on it is erased.
    • Internal storage, only where the PC has another internal disk: use it as internal storage, for backups and for music if you want (it is formatted, everything on it erased), or leave it as it is.
    • Your shared folder's user name and password: the user name in lower case letters and figures, starting with a letter (music is offered); the password 8 characters or more, typed twice. The same password is asked for by every change on the system page, so keep it.
    • The network: from the router (DHCP, recommended), or a static address (address/prefix, gateway and DNS).
    • Mandarin Bridge: whether to install it here as well. Say yes if a USB DAC will be plugged into this PC: Mandarin Bridge is how Mandarin plays a DAC on the computer it runs on, as a room of its own. It can be installed or removed later on the system page.
  5. Type erase to go on. Mandarin OS is written to the disk, which takes a few minutes.
  6. At the end it says it is installed. Press Enter: the computer switches off. Then take the USB stick out and switch the computer on. It starts from its own disk, and a minute or two later Mandarin is at http://<box address>:3500.
Take the stick out only once the computer is off: the installer runs from it.
  1. Open http://<box address>:3500 (its screen shows the address, e.g. http://192.168.0.57:3500) on a device at home and create your account, or choose Use without an account.
  2. Copy your music into the shared folder's Storage, or plug in a USB drive with music on it. Albums appear as they are read.
  3. Pick a room under Settings → Audio Devices, tap an album and Play Now.

Using Mandarin OS

The box's address. Everything below is reached at the box's address on your network, such as 192.168.0.57: its screen shows it, and so does your router's list of devices. Reserve that address for the box in your router (a DHCP reservation, or a static address on the system page's Network & Access tab) so it never changes. Computers and iPhones usually find the box as mandarin.local too, and mandarin works where the router names the devices on its network; an Android phone often finds neither. The address always works.

Mandarin

Mandarin is at http://<box address>:3500. It is the same Mandarin as everywhere: the app, the web page, Sonos, the streamers and Bridges, Qobuz and Tidal, its settings. Its music folder is the shared folder's Storage, USB drives and internal storage included. Shut down in Mandarin (☰, the power button) shuts the computer down too; its power button starts it all again.

The system page

http://<box address>/ (no port) is Mandarin OS's own page. Anyone at home can read it; every change asks for the shared folder's password (five wrong in five minutes, and it stops trying for five minutes).

  • Overview: Mandarin answering, its version and library, and each of its services running or not.
  • Storage: the data partition's space; each USB drive, whether it is read-only and why, and Eject before you unplug it; a Linux drive from another computer made the shared folder's; internal storage, where another internal disk can be formatted for it (you type erase first; never the system's disk or a USB drive).
  • Network & Access: the address now; DHCP or a static address, which is checked before it is taken and put back by itself after two minutes unless you keep it from the new address; a connection test, layer by layer; the shared folder and its user.
  • Settings: Mandarin OS's version, with Update and restart when a newer one is out and Check for updates (below); Mandarin Bridge installed or removed (for a USB DAC plugged into the box), and the weekly upkeep's last run.
  • Support: every log on the box as one text file (Download all logs), and Mandarin's, Mandarin OS's and the system's logs read and filtered on the page; Reinstall Mandarin (put back from its latest release, your library, settings and music kept) and Reset Mandarin (it starts as new, its library, account and settings set aside in its Backups folder, not deleted).
  • The power menu (⏻, top right): restart Mandarin, restart the computer, or shut it down.

The shared folder

smb://<box address>/data, or \\<box address>\Data on Windows, with the user name and password chosen at install.

  • Storage: copy your music in here. Each USB drive plugged in is under Storage/USB, by its name, and internal storage is Storage/Internal.
  • Installer: Reinstall Mandarin's own folder.
  • MandarinServer, MandarinBridge, MandarinApp and MandarinOS: the logs (and Mandarin's backups), read-only.

USB drives

A USB drive is mounted as it is plugged in, checked first, and its music is in Mandarin: ext4, exFAT, FAT and NTFS, and a Mac drive (HFS+) read-only. One whose filesystem can't be repaired is mounted read-only, and the system page says why. Eject it on the system page before you unplug it.

A Linux drive (ext4) from another computer keeps the owners its files were given there: the shared folder copies music from it, but moving, renaming or deleting on it is refused (“Access denied”). The system page's Storage tab says so beside the drive; Make them the shared folder's (with the shared folder's password) makes its files the shared folder's, and then they can be moved, renamed and deleted. Only that drive is changed, and a big one takes a few minutes. exFAT, FAT and NTFS drives need nothing: they are the shared folder's as they are plugged in.

The box's own screen

With a screen plugged in, the box shows its version, where to find Mandarin, the system page and the shared folder, and whether Mandarin is running. It takes two words, typed with a keyboard and then confirmed with yes:

  • networkreset: the network back to DHCP, and the computer started again. For a static address that lost the box.
  • passwordreset: Mandarin's account removed and every device signed out, for a forgotten password. Your library, edits and history stay; create the account again in a browser.

There is no login and no SSH: the screen and the system page are the ways in.

Updates and upkeep

Once a week, when nothing is playing (no room playing, no scan under way), Mandarin OS takes a newer Mandarin OS where one is out (below), or else Debian's security updates, removes what nothing needs any more, restarts only if an update needs it, and then checks that everything works, starting again whatever isn't. Each step is in its log.

Mandarin and Mandarin Bridge update from Mandarin's Settings → Updates, as everywhere (Updating).

Updating Mandarin OS

From 0.1.4, Mandarin OS updates itself in place, without reinstalling. The system disk has two system partitions: the version running is on one, and a new version is written onto the other, never over the one running. The box looks for a newer version once a day.

  • On the system page: Settings shows Mandarin OS's version and, when a newer one is out, Update and restart (with the shared folder's password). It downloads the new version into the data partition, checks its checksum and its signature (Mandarin's release key, as Mandarin's own updates), writes it beside this one, and starts the computer again on it: music stops for a few minutes. Check for updates looks at once.
  • By itself: the weekly upkeep puts a newer version in, while nothing plays, and starts the computer again only when nothing plays.
  • If it doesn't start, or starts without what the box needs (the data partition, the shared folder, the network, the system page, and Mandarin if it answered before), the computer tries it three times, then goes back by itself to the version that worked, which the update never touched. The system page then says the update didn't start and the box went back to the version before. The weekly upkeep never tries that version again; Update and restart can.
  • What is kept: everything on the data partition (your music, Mandarin's library and settings) and on USB drives is never touched. The box's own settings are carried into the new version: the shared folder's user, password and its files' owner, the network as set (a static address included), Mandarin Bridge if installed, and Mandarin itself where the one running is newer than the image's (it is never put back to an older one).
Installed with 0.1.3 or earlier? Those can't update themselves (the updater came with 0.1.4, and the users their files belong to are numbered otherwise): reinstall 0.1.6 once from the USB stick. Reinstalling erases the system disk, the data partition with it (Mandarin's library and settings, and music copied into Storage on that disk), so first make a backup in Mandarin (Settings → Backup & restore, Back up to the server) and copy it off the box from the shared folder (MandarinServer/Backups), with any music in Storage; afterwards, restore it in Mandarin from that file. Music on USB drives isn't on the system disk and isn't touched. From 0.1.4 on, it updates itself.
