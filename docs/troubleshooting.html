Troubleshooting

http://<server-ip>:3500/api/health answers without signing in; /api/status (signed in) says what the server can see.

No rooms

"No Sonos rooms found yet"

Check the container is on host networking and on the same subnet as the speakers, then look at sonos.error in /api/status. Setting SONOS_HOSTS to one speaker's IP skips discovery.

Silence

A room skips every track

The speakers can't reach the server. On a machine with several network interfaces set SERVER_IP to its LAN address, and check nothing blocks the port.

No albums

The library is empty

/api/status shows music_dir and index_count. Check the -v …:/music:ro mount and that the folder is readable.

Hi-res

96 kHz files won't play

/api/health must say "ffmpeg": true. The Docker image includes it; a hand-run server needs ffmpeg on the PATH.

Sign-in

Asked to sign in with the sign-in off

Without a sign-in, a device must ask by a name used at home (an address, a bare name, or one ending .local, .lan, .home.arpa or .ts.net), from your home network or tailnet. Behind a reverse proxy on the same machine, the proxy must pass on who asked. See Your account.

Android

“Mandarin stopped in the background”

The app says so when Android ended it while you weren't using it, with Android's own words. If it comes back, save the log (Settings → Setup → Logging → Save log) and send it (Logs).

Forgot it

The password

docker exec musicd-server /app/server/bin/mandarin-server reset-password, then create the account again from a device at home.

DSD

DoP from a Linux Bridge, native DSD from Android

Linux's USB audio driver offers a DAC native DSD only where its own list knows the DAC's maker; any other is given DSD as DoP. The Bridge's page (http://<it>:49494/) and log say when the kernel holds it back, with the one line for /etc/modprobe.d that frees it; then unplug the DAC and plug it in again. See Mandarin Bridge.

A click

A click as the rate changes

A Mandarin Bridge gives its DAC half a second of silence at a change of rate between tracks. A Squeezelite player pauses for as long as its -r option says: start it with -r 44100-768000:500.

Mandarin Bridge

A Bridge isn't listed

Open its page (http://<it>:49494/, or the Android app itself) to see that it runs and which DAC it plays to, then Look again in Settings → Audio Devices. A Bridge found is off until you switch it on there.
